# Ilona’s Art

A static art portfolio with a cream, terracotta, and olive palette.

## Finish the content

- Add the artist’s public email to `artistEmail` in contact.js. Inquiry links remain inactive until it is supplied.
- Replace the three artwork placeholders in index.html with artwork images, titles, medium, and year. Set each corresponding data-artwork value to its real title.
- Replace the draft notice with the artist’s bio or remove it before publishing.

## Publish on GitHub Pages

Upload index.html, contact.js, .nojekyll, and any artwork images into a public repository. In Settings → Pages, choose Deploy from a branch, main, and / (root), then Save.

GitHub Pages provides the static hosting. Inquiry links open the visitor’s email app with a subject and message; the visitor must send the message. No payment is collected and no email is sent automatically.

GitHub restricts Pages sites primarily directed at commercial transactions. If the portfolio becomes an online shop, use a suitable host such as Cloudflare Pages instead.
